# Nepal Political Unrest Analysis (SS112)

This project analyzes the recent youth-led political unrest in Nepal (2022-2025) using complexity science frameworks. It combines quantitative data from ACLED and World Values Survey with qualitative analysis.

## Project Structure

- `Draft.md`: The main essay/paper draft.
- `research/`: Contains research notes, data summaries, and background information.
- `scripts/`: Python scripts used for data visualization.
- `visualizations/`: Generated charts and figures used in the paper.
- `ACLED Data_2025-12-09.csv`: Source data for conflict events.

## Visualizations

The project includes several visualizations generated from the data:
- ACLED Event Counts
- Political Timelines
- Phase Space Diagrams

## Usage

To regenerate the visualizations, run the scripts in the `scripts/` directory. Ensure you have the required Python packages installed (`pandas`, `matplotlib`, `seaborn`).
